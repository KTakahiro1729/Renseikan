# データ編集の注意

ゲーム定義は `game.json`。編集項目の一覧と例はリポジトリ直下のREADMEを参照してください。

JSONではコメントを書けません。補足は `provisional` の文字列配列に記載します。文字列はダブルクォートで囲み、最後の要素に余分なカンマを付けないでください。

タスクの `kind` は実装済みの行動名です。`require` は `null`、`foreign`（外国語）、`used`（使用後）、`book`（書籍）。`copies` はそのカードの枚数です。未実装の行動名を指定しても新しいゲーム処理は作られません。

`descriptions` は `unused`（使用前）、`used`（使用後）、`tampered`（工作後）。深い調査では直前に保存した描写が提示されます。
